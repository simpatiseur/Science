Les Lentilles
⏱ Durée estimée : 4 heures · Compétence 1 – Optique
Compétence Traiter une situation relative à l'optique, notamment distinguer les lentilles, déterminer leurs foyers et construire l'image d'un objet à travers une lentille convergente.
Thème Optique – Leçon 1 sur 2
Leçon 1 : Les Lentilles
A. Situation d'apprentissage

Le conseil d'enseignement de Physique-Chimie du Lycée Moderne de Dimbokro organise un concours à l'intention des élèves de 3ème. Ce concours porte sur l'utilisation des lentilles.

Pour se donner toutes les chances de ravir la première place, les élèves de la classe de 3ème 6 se proposent de :

  • Distinguer les lentilles convergentes des lentilles divergentes ;
  • Déterminer le foyer d'une lentille ;
  • Construire l'image d'un objet à travers une lentille convergente.

C'est pour répondre à ces objectifs que nous allons étudier cette leçon.

B. Contenu de la leçon
1 – Les types de lentilles

a) Définition

Une lentille est un milieu transparent limité par deux surfaces dont au moins l'une est courbe (sphérique). Les lentilles sont généralement en verre ou en plastique transparent.

b) Lentille convergente

Une lentille convergente est plus épaisse au centre qu'aux bords. Elle fait converger (se regrouper) un faisceau de lumière parallèle en un seul point appelé foyer image F'.
🔍 Elle a un effet de loupe.
Schéma – Lentille convergente

c) Lentille divergente

Une lentille divergente est plus mince au centre qu'aux bords. Elle fait diverger (s'écarter) un faisceau de lumière parallèle.
👓 Elle est utilisée pour corriger la myopie.
Schéma – Lentille divergente
2 – Caractéristiques d'une lentille convergente

a) Distance focale et vergence

La distance focale f est la distance entre le centre optique O et le foyer image F'. Elle s'exprime en mètre (m).
La vergence C (ou puissance) d'une lentille est l'inverse de la distance focale :

C = 1/f avec C en dioptrie (δ) et f en mètre (m).
• Lentille convergente : C > 0 (vergence positive)
• Lentille divergente : C < 0 (vergence négative)
• Deux lentilles accolées : C = C₁ + C₂
Exemple 1

Une lentille convergente a une distance focale f = 25 cm.

  1. Convertis f en mètre.
  2. Calcule la vergence C de cette lentille.
  3. Cette lentille est-elle convergente ou divergente ?
✅ Solution

1. f = 25 cm = 0,25 m

2. C = 1/f = 1/0,25 = 4 dioptries (δ)

3. C = +4 δ > 0, donc c'est une lentille convergente.

Exercice de fixation 1

Une lentille a une vergence C = –5 δ.

  1. Cette lentille est-elle convergente ou divergente ? Justifie.
  2. Calcule sa distance focale f.
  3. Deux lentilles accolées ont des vergences C₁ = 4 δ et C₂ = 2 δ. Calcule la vergence équivalente.

1. C = –5 δ < 0, donc c'est une lentille divergente.

2. f = 1/C = 1/(–5) = –0,2 m = –20 cm

3. C = C₁ + C₂ = 4 + 2 = 6 δ

3 – Image d'un objet à travers une lentille convergente

a) Les rayons particuliers

Pour construire l'image d'un objet, on utilise deux rayons particuliers :

Rayon 1 : Tout rayon parallèle à l'axe optique passe, après la lentille, par le foyer image F'.

Rayon 2 : Tout rayon passant par le centre optique O n'est pas dévié (il passe tout droit).

b) Positions de l'image selon la position de l'objet

Position de l'objet Image obtenue
Objet au-delà de 2F Image réelle, renversée, plus petite
Objet sur 2F Image réelle, renversée, même taille
Objet entre F et 2F Image réelle, renversée, agrandie
Objet entre F et O Image virtuelle, droite, agrandie

c) Le grandissement

Le grandissement γ est le rapport entre la taille de l'image et la taille de l'objet :
γ = taille image / taille objet = OA' / OA
• Si |γ| > 1 : l'image est agrandie
• Si |γ| < 1 : l'image est réduite
• Si γ < 0 : l'image est renversée
• Si γ > 0 : l'image est droite
Exemple 2

Un objet AB de taille 2 cm donne une image A'B' de taille 6 cm à travers une lentille convergente.

  1. Calcule le grandissement.
  2. L'image est-elle agrandie ou réduite ?
  3. L'image est-elle droite ou renversée ?
✅ Solution

1. γ = 6/2 = 3

2. |γ| = 3 > 1, donc l'image est agrandie.

3. γ = +3 > 0, donc l'image est droite.

Exercice de fixation 2

Un objet de taille 4 cm donne une image de taille 2 cm à travers une lentille.

  1. Calcule le grandissement γ.
  2. L'image est-elle agrandie, réduite ? Justifie.
  3. L'image est-elle droite ou renversée ? Justifie.

1. γ = 2/4 = 0,5

2. |γ| = 0,5 < 1, donc l'image est réduite.

3. γ = +0,5 > 0, donc l'image est droite.

4 – L'appareil photographique
L'appareil photographique fonctionne sur le même principe qu'une lentille convergente :
• L'objectif joue le rôle de la lentille convergente.
• La pellicule (ou capteur numérique) joue le rôle de l'écran.
• L'image se forme sur la pellicule : elle est réelle, renversée et réduite.
🔑 À retenir absolument
  • Lentille convergente → plus épaisse au centre → C > 0.
  • Lentille divergente → plus mince au centre → C < 0.
  • Vergence : C = 1/f (en dioptries δ, f en mètres).
  • Deux lentilles accolées : C = C₁ + C₂.
  • Grandissement : γ = taille image / taille objet.
  • Appareil photo : objectif = lentille · pellicule = écran → image réelle et renversée.
📝 Exercices d'application
Exercice 1
Application

On donne les vergences suivantes : C₁ = 6 δ ; C₂ = –4 δ ; C₃ = 10 δ.

  1. Pour chaque lentille, dis si elle est convergente ou divergente.
  2. Calcule la distance focale de chaque lentille.
  3. Calcule la vergence équivalente de C₁ et C₃ accolées.

1. C₁ = 6 δ > 0 → convergente ; C₂ = –4 δ < 0 → divergente ; C₃ = 10 δ > 0 → convergente

2. f₁ = 1/6 ≈ 0,167 m ≈ 16,7 cm ; f₂ = 1/(–4) = –0,25 m = –25 cm ; f₃ = 1/10 = 0,1 m = 10 cm

3. C = C₁ + C₃ = 6 + 10 = 16 δ

Exercice 2
Application

Un objet AB de hauteur 3 cm est placé devant une lentille convergente de vergence C = 5 δ.

  1. Calcule la distance focale f de la lentille.
  2. L'image A'B' obtenue a une hauteur de 9 cm. Calcule le grandissement.
  3. L'image est-elle droite ou renversée ? Agrandie ou réduite ?

1. f = 1/C = 1/5 = 0,2 m = 20 cm

2. γ = 9/3 = 3

3. γ = +3 > 0 → image droite ; |γ| = 3 > 1 → image agrandie.

Exercice 3
Application

Complète le tableau suivant :

LentilleVergence C (δ)TypeDistance focale f (cm)
L₁+8??
L₂–2??
L₃?Convergente50

L₁ : convergente · f = 1/8 = 0,125 m = 12,5 cm

L₂ : divergente · f = 1/(–2) = –0,5 m = –50 cm

L₃ : f = 50 cm = 0,5 m · C = 1/0,5 = +2 δ

Exercice 4
Approfondissement

Un photographe utilise un appareil dont l'objectif a une vergence de 40 δ.

  1. Calcule la distance focale de l'objectif.
  2. Explique le rôle de l'objectif et de la pellicule dans la formation de l'image.
  3. Un objet de 5 m de hauteur est photographié. Son image sur la pellicule mesure 2 cm. Calcule le grandissement. L'image est-elle renversée ?

1. f = 1/40 = 0,025 m = 2,5 cm

2. L'objectif est une lentille convergente qui capte la lumière et forme l'image. La pellicule (ou capteur) est l'écran sur lequel se forme l'image.

3. γ = 0,02/5 = 0,004 · |γ| < 1 → image réduite · γ > 0 → image droite en valeur absolue. En réalité l'image est renversée (sens négatif) et très réduite.

Exercice 5
Approfondissement

Deux lentilles L₁ (convergente, f₁ = 20 cm) et L₂ (divergente, f₂ = –50 cm) sont accolées.

  1. Calcule les vergences C₁ et C₂.
  2. Calcule la vergence équivalente C du système.
  3. Calcule la distance focale équivalente. Ce système est-il convergent ou divergent ?

1. C₁ = 1/0,20 = +5 δ · C₂ = 1/(–0,50) = –2 δ

2. C = C₁ + C₂ = 5 + (–2) = +3 δ

3. f = 1/3 ≈ 0,333 m ≈ 33,3 cm · C > 0 → système convergent.
